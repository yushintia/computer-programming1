## Conventions

Every solution follows the Style Guide appendix: mandatory file
header block, snake_case variables/functions, `SCREAMING_SNAKE`
constants, 4-space indentation, always-braced control statements, and
compiles clean under `gcc -Wall -Wextra -std=c99`.
